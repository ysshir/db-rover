## 接続を追加する

サイドバー（アクティビティバーの **DB Rover**）の **＋** アイコン、またはコマンドパレットの
`DB Rover: 接続を追加` でフォームが開きます。

- **PostgreSQL / MySQL(MariaDB)**: ホスト・ポート・データベース・ユーザーを入力します。
- **SQLite**: ファイルパスだけを入力します（ワークスペース相対・絶対・`~` 展開に対応）。

フォームの **接続テスト** でその場に疎通を確認できます。

> パスワードは VS Code の SecretStorage にだけ保存されます。`settings.json` には書き込まれません。
