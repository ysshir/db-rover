## SQL を実行する

接続を右クリック →「SQL エディタを開く」、またはコマンドパレットの
`DB Rover: SQL エディタを開く` でエディタが開きます。`.sql` ファイルでもそのまま使えます。

文の区切りは `;` です。実行の仕方は 3 通りあります。

| 操作 | 実行されるもの |
| --- | --- |
| `Cmd/Ctrl+Enter` → `Enter` | カーソルに一番近い 1 文 |
| 各文の上の `▷ 実行`（CodeLens） | その 1 文 |
| `Cmd/Ctrl+Shift+Enter` | すべての文 |

`Cmd/Ctrl+Enter` は **2 段階**です。1 回目で対象の文がハイライトされ、そのまま `Enter`
（または `Cmd/Ctrl+Enter` をもう一度）で実行します。何が走るのかを実行前に確認するためです。
`Escape` でハイライトを解除できます。範囲を選択しているときは、ハイライトを挟まずそのまま実行します。

結果は下部パネル（ターミナル・出力と同じ場所）の **DB Rover** タブに出ます。CSV でコピー・保存できます。
